# Get on the T

**Squash Club Organiser.** An app for whoever runs a squash club's evenings.
Club nights come first: people come and go, courts come and go, and the app
queues players of similar ability onto courts so that everyone gets a fair
share of court time and nobody sits out too long. Team round robins and
knockouts will follow.

This repository is the app's public front door:

- **[Ask for a feature or report a problem](https://github.com/vanstoner/get-on-the-t/issues/new/choose)**.
